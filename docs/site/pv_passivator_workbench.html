What r2SCAN labels need next

  • No r2SCAN references exist for any passivator. The 2024 REAG set is PBE+D3(zero) and cannot be mixed with r2SCAN slabs. Each case needs its own reference jobs, and the bundles already include them.
  • The r2SCAN archive covers defects and small anions (Ac, Cl, TFA, PbI3) but no organic passivators. The first label set would be bare and Schottky slabs plus the PEAI, PEAAc and PEATFA complexes at several poses.
  • Please check: is putting the NH3 group into the FA+ vacancy and I− into the I vacancy (the exchange view) the configuration you used before?
